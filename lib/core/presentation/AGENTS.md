# presentation

## Purpose
앱 전체에서 재사용되는 공통 UI 위젯. 글라스모피즘 카드, 스코어보드, 상태 태그, 게이지 등 게임 UI 컴포넌트를 제공한다.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `widgets/` | 공통 위젯 컴포넌트 (see `widgets/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- 2개 이상의 feature에서 사용되는 위젯만 이곳에 배치
- 단일 feature 전용 위젯은 해당 feature의 `presentation/widgets/`에 배치
